# mla-advisory

Skills for the Advisory team at MLA Canada — competitive analysis, research tooling, and market intelligence.

## Skills bundled
- `unit-mix-summary` — Generates a unit mix summary Word document for multi-family competitive set analysis across multiple projects.
- `project-breakdowns` — Builds a presale unit pricing analysis Excel workbook from floor plan images and price sheet data for MLA Advisory.
- `stabilized-table` — Builds the MLA Stabilized Rental Chart (Word, landscape) with leasing periods and leases-per-month calculated from the printed period, plus a verified velocity writeup.
- `unit-mix-overview` — Builds the transposed Unit Mix Overview page (plan types as columns, INVENTORY/MIN/MAX/AVERAGE/MEDIAN rows) aggregating unit-mix-table output, one or more comp sets per page.
